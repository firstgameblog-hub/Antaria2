# Хроники Антарии — план разработки

> Браузерная сюжетная RPG о превращении умирающей деревни в большой город.
> Стиль подачи: игра читается как книга, всё вплетено в сюжет, без «списка квестов ради квестов».
> Отметка прогресса: `- [ ]` — не начато, `- [x]` — готово.
