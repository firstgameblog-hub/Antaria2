# Хроники Антарии

**Играть онлайн:** <https://firstgameblog-hub.github.io/Antaria2/>

Браузерная сюжетная RPG о превращении умирающей деревни в большой город.
Игра читается как книга: стадия деревни — глава, задания приходят письмами
и разговорами, а не списком квестов.

Сейчас собраны **вертикальный срез этапа 2**, **карта деревни (3.1)**,
**стройка (3.2)** и **переход стадий (3.3)**: 25 построек, уровни, рабочие,
эффекты деревни и сцена перехода на вторую стадию с новой картой.

## Как запустить

Нужен Node.js (18+). Открывать `index.html` файлом нельзя: браузер блокирует
ES-модули через `file://`.

```bash
node tools/serve.mjs
```

Затем откройте <http://localhost:8123>.

На Windows можно дважды щёлкнуть `start.cmd` — он поднимет сервер и откроет
браузер.

Порт по умолчанию 8123, меняется переменной `PORT`:

```bash
set PORT=9000 && node tools/serve.mjs
```

## Как играть

1. Прочитайте главу I — она открывается сама при новой игре. Время на чтение
   останавливается.
2. Нажмите на точку карты: двор, опушка, луг, ручей, частокол, костёр,
   дом травницы или ворота. Под картой появятся описание и действия.
3. Собирайте ресурсы, чините частокол, готовьте на костре, торгуйте с Аскольдом
   и стройте: вкладка «Стройка» показывает цены, время и эффекты.
4. «Лечь спать до утра» на дворе запускает смену суток: экран темнеет,
   обновляются узлы сбора, завершаются крафт и стройка.
5. Следите за карточкой «Письмо отца» — в ней три шага и прогресс.

Хроника записывает ключевые события, сохранения лежат в localStorage.

## Что уже работает

- Книга: глава I, выбор реплики, «сбой системы», письмо-задание, пауза времени.
- Карта: SVG-схема деревни, 8 интерактивных точек с подписями, активная
  точка подсвечивается; клик меняет описание и действия. Ремонт частокола
  закрывает пролом, вышка и пристройки дома старосты появляются после стройки.
- Стройка: 25 построек на 7 стадий, уровни (лачуга → дом → особняк),
  рабочие, время в игровых минутах, очередь и суммарные эффекты деревни —
  жильё, склад, защита, уют, еда.
- Стадии: карточка «Следующая стадия» с целями и прогрессом, переход 1 → 2
  отдельной сценой, новая карта и разблокировка построек и рецептов.
- Локации: двор, опушка, луг, ручей, частокол, костёр, дом травницы, ворота.
  Сбор трав/ягод/веток занимает 2–2.6 секунды, показывает полосу прогресса
  и обновляется за ночь.
- Крафт: отвар и вяленые ягоды, очередь с игровым временем, готовность
  приходит даже в другой вкладке.
- Торговля: Аскольд покупает и продаёт, цены зависят от торгового чутья.
- Квест: «Письмо отца» с тремя шагами, прогрессом и наградой.
- Инвентарь: ячейки-стопки, характеристики героя (сила, ловкость,
  торговое чутьё, доверие).
- Время: пауза, скорости ×1/×2/×4, сон с затемнением и сменой суток,
  автосохранение на смене дня.
- Сохранения: ручное и авто в localStorage, экспорт и импорт JSON-файла.
- Хроника: записи о главе и заданиях видны сразу.
- Сцена: огонь и дым на карте анимированы через CSS.
- Бой, охота и набеги не реализованы (этап 8).
- Звук: ветер и щелчок интерфейса на WebAudio.
- Проверка данных при старте: битые ссылки и координаты точек пишутся
  в консоль.

## Упрощения среза

- Карта меняется точечно: частокол, дом старосты и вышка. Наборы карт есть
  для стадий 1–2; для следующих стадий карты появятся позже.
- Переход к второй стадии работает; цели для 2 → 3 появятся вместе с контентом.
- Население пока не растёт само: жильё считается, но прироста жителей нет (этап 6).
- Часть эффектов (склад, уют) пока только считается и показывается,
  но не влияет на механики.
- Продажа идёт по одному предмету; продажа партией — следующая правка.
- Характеристики — черновик: на цены влияет только торговое чутьё.
- Торговец не обновляет запас и не уезжает.
- Глава I занимает 5 страниц; полный текст лежит в `docs/chapter_01.md`.

## Проверка данных

```bash
npm run check
```

Скрипт проверяет ссылки между справочниками (ресурсы, рецепты, постройки,
локации, торговцы, стадии) без запуска браузера.
